# Local Dev Docs
**Русский** | [English](README.md)

Локальная документация для заметок по Laravel, PHP, Git, собеседованиям и рабочим шпаргалкам.

## Как это устроено

Проект состоит из:

- `public/index.php` — главная страница и генерация меню из папок
- `public/block.php` — безопасная отдача HTML-блоков
- `public/assets/js/app.js` — стартовый скрипт инициализатор
- `public/assets/js/core/App.js` — главный скрипт приложения
- `public/assets/js/modules` — модули приложения для загрузки документов, поиска и содержания текущей статьи
- `public/assets/css/app.css` — стили
- `storage/blocks/` — сами документы в виде отдельных `.html` файлов

## Структура проекта

```text
docs/
  public/
    index.php
    block.php
    assets/
      js/
        app.js
        core/
          App.js
        modules/
          DocLoader.js
          Search.js
          TableOfContents.js
      css/
        app.css
  storage/
    blocks/
      laravel/
        middleware.html
        service-provider.html
      git/
        templates-commands.html
```

## Как это работает

1. `index.php` сканирует папку `storage/blocks`
2. Находит все `.html` файлы
3. Строит меню автоматически по структуре папок
4. При клике JS запрашивает нужный блок через `block.php`
5. `block.php` проверяет путь и отдаёт только разрешённый `.html` файл
6. После загрузки документа JS строит содержание по его заголовкам

## Как запускать

Из папки `public`:

```bash
php -S localhost:9999
```

После этого открыть в браузере:

<a href="http://localhost:9999" target="_blank">http://localhost:9999</a>

## Как добавлять новые статьи

Просто создать новый `.html` файл внутри `storage/blocks`.

Примеры:

```text
storage/blocks/laravel/queues.html
storage/blocks/php/interfaces.html
storage/blocks/interviews/laravel/middleware-short.html
```

После обновления страницы новый файл автоматически появится в меню.

## Важные правила

- Блоки документации хранятся только в `storage/blocks`
- Разрешены только файлы `.html`
- Структура меню строится из папок автоматически
- Если файл не появился, проверь расширение и путь
- Если меняется код проекта, обновляй `README.md` и `README_ru.md`, когда меняется поведение, структура или способ запуска

## Для чего нужен `block.php`

`block.php` нужен для безопасной загрузки блоков.

Он:

- принимает путь к файлу
- проверяет, что файл реально находится внутри `storage/blocks`
- запрещает выход за пределы папки
- отдаёт только `.html`

Это нужно, чтобы случайно не открыть `.env`, `.php`, `.json` или другие лишние файлы.

## Если что-то не работает

### Не грузится блок
Проверь:

- запущен ли локальный PHP-сервер
- существует ли файл
- правильный ли путь
- имеет ли файл расширение `.html`

### Новый файл не появился в меню
Проверь:

- лежит ли он внутри `storage/blocks`
- расширение файла точно `.html`
- нет ли ошибки в названии папки
